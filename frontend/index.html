Runtime configuration

The gateway follows its selected network adapter automatically. Fixed overrides and other listener changes require an application restart.

Security & visibility boundaries

  • Administration requires a password login and a protected session. The management listener is loopback.
  • Forwarded client-IP headers are discarded. The socket peer supplies rate-limit identity.
  • Only explicit upstream IP addresses are allowed. Redirects are not followed.
  • External reachability is untested. No state implies comprehensive attack detection.
  • No Windows Firewall rules are read or modified by this application.
  • Network gateway access requires TLS. Keep backend ports private and restrict host access.

Preserves API routes, policies, and administrator audit history.

SQLite data storage

Persistent application records and restart-safe rate-limit windows.

Backups use SQLite's consistent snapshot API. Only password hashes and hashed session identifiers are stored; plaintext passwords, cookies and full request bodies are excluded. Clearing history preserves configurations, current discovery/verification, rate windows and audit records.
